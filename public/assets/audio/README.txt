FOLDER FILE MP3 AUDIO PLAYER
============================
Silakan masukkan file .mp3 kamu ke dalam folder ini:
Path: public/assets/audio/

Contoh nama file default:
1. track-1.mp3 (misal: Wouldn't It Be Nice)
2. track-2.mp3 (misal: God Only Knows)
3. track-3.mp3 (misal: A Day in the Life)
4. track-4.mp3 (misal: Echoes)
5. track-5.mp3 (misal: Bohemian Rhapsody)

Kamu juga bisa menambahkan file mp3 dengan nama custom dan mendaftarkannya di src/data.json pada bagian "aestheticSettings.audioTracks".
